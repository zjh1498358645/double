# 双人秘密基地：实时游戏与好友邀请设计

日期：2026-10-05。状态：设计方向已获同意；本文已获用户确认，按已批准计划实施。

## 目标与范围

手机上操作立即反馈，伙伴持续看到绘画、落子、聊天与邀请；降低目前 HTTP 写入后再轮询造成的等待。当前绑定的伙伴以好友卡片呈现，可直接邀请进入游戏。保留现有 20 种游戏、私人钥匙、配对关系、照片、信箱和星星记录，沿用 GitHub Pages 正式网址与免费服务。

本次完善现有游戏的同步与操作反馈，不增加公共匹配、多好友关系、语音或新的游戏规则。微信邀请继续提供可复制的房间链接；站内好友邀请无需经过微信分享。

## 架构与部署

保留 D1 与现有纯游戏引擎作为持久状态及胜负、奖励的权威来源。新增独立 Cloudflare Worker，导出 SQLite Durable Object，每个小屋对应一个对象，负责连接、在线状态、即时绘画和状态推送。Pages API 通过跨 Worker 绑定访问对象。

浏览器连接 `wss://double-secret-base-api.pages.dev/api/base/realtime`，通过现有 Pages 域名转发升级请求，不依赖手机先前无法访问的 workers.dev 域名。`build/cloudflare-worker.ts` 对 WebSocket 101 响应直接保留升级附件，不能沿用普通 Response 重建流程。新的 Worker 禁用公共入口；内部注册票据与发布状态只允许绑定调用。

先部署实时服务，再部署带绑定的 Pages API，最后发布前端。所有新增资源使用免费方案，采用 SQLite 对象与 WebSocket 休眠；不启用付费升级。若账户权限或平台限制阻止免费部署，保留已有网站并报告具体阻碍。

官方依据：Pages 需要绑定独立部署的 Durable Object Worker，见 [Pages bindings](https://developers.cloudflare.com/pages/functions/bindings/#durable-objects)；免费方案支持 SQLite Durable Objects，见 [Durable Objects pricing](https://developers.cloudflare.com/durable-objects/platform/pricing/)。免费额度不能视为无限容量。

## 身份、权限与协议

新增经过现有钥匙身份验证的 `POST /api/base/realtime-ticket`。返回随机、60 秒有效、一次性连接票据；绑定用户、小屋、成员槽位、成员代际及允许的前端 Origin。长期钥匙不进入 WebSocket URL。票据不记录日志，响应禁止缓存；消费记录存于对象存储，以保证对象重启后仍不能重放。

连接成功返回协议版本、连接标识、当前成员代际和用户专属快照。客户端消息包含协议版本、消息类型、游戏 ID、回合代际及递增序号。绘画消息还包含笔画 ID、画笔属性与新增点；单包最多 8 KB、最多 60 个点，每连接最多每秒 30 包。非法字段、越权角色、旧游戏或旧回合消息拒绝，不执行游戏动作。

对象绑定 D1，在连接、唤醒及敏感绘画校验时核实成员和当前游戏代际；短缓存最多 1 秒。退出或更换成员的 API 写入必须通知对象关闭旧连接、清除预览和作废票据。缓存期内任何绘画包也只发给仍属于同一成员代际的连接。

服务端按每个成员分别生成现有 filtered view；不向客户端广播完整私有引擎状态。画题、对方手牌、隐藏答案及独立线索保持现有可见性规则。

## 持久动作与推送

落子、出牌、猜题、聊天、邀请与结束继续走现有授权 API、版本比较及请求 ID 去重。写入成功后，将小屋版本和两个成员各自可见的快照发布到对象，再推送给对应连接。提交响应携带最新快照，操作者不用再等待 GET 才显示结果。

客户端只接受同一成员代际内更高的持久版本，迟到的 HTTP 响应或推送不能回滚画面。重复请求不能重复结算星星。安全可逆的操作可先展示待确认反馈；失败恢复权威状态并显示可重试提示。隐藏选择不做猜测性渲染。

发布失败不能撤销已经成功的 D1 写入。发送者收到成功状态，同时客户端进入重新校验；连接每 15 秒进行轻量版本核对，发现缺口补拉快照，避免漏推送永久停留。正常连接期间停止 500ms 全量轮询。断线期间恢复原有自适应轮询，重连采用 1、2、4、8、15 秒上限及随机抖动；重新进入前台立即尝试连接并拉取快照。

## 你画我猜

保持平滑 SVG 线条、颜色、独立画笔和橡皮。采样与本地呈现使用 pointer events、合并采样与 requestAnimationFrame；本地绘制不等待网络。

约每 40ms 把新增点发送到实时通道。对方按笔画序号增量追加线条，避免每次重建整个画布。结束笔画立即通过已有 API 保存最终笔画；长笔画每 1 秒或达到现有点数上限时保存检查点并继续下一段，降低断线丢失范围。未确认段保留在当前登录会话内存中，重连后使用同一 ID 重试；刷新前未保存的草稿仍可能丢失。

实时预览与持久笔画合并显示；只有持久确认覆盖对应段后才移除预览，避免短暂消失。乱序点暂存小窗口，序号缺口请求该笔画的完整预览。撤销、清空、猜中或换题更换绘画代际并清除旧预览，旧包不能重新出现。对象重启后恢复持久笔画，客户端重发尚未确认的当前段。

绘画者角色由服务端校验；预览消息永不包含题目。公屏聊天与猜测结果立即推送，胜负仍由原引擎判定。

## 好友入口与邀请

新增当前伙伴卡片：现有头像、昵称、在线／暂离／离线状态，以及“邀请一起玩”。选择现有游戏后创建持久邀请。双方展示两个头像及“等待回应／已准备”等明确状态；伙伴在任何页面收到游戏名称和邀请者信息，可接受或拒绝。

接受使用现有 game-accept，进入同一局；拒绝新增明确的 game-decline 操作，结束该邀请并通知发起者。离线时邀请保留在现有小屋游戏记录内，上线后呈现。重复推送按游戏 ID 去重。已有进行中的游戏显示“继续本局”，不由新邀请覆盖。现有外部邀请链接继续可用。

在线状态以有效连接为依据；页面隐藏报告暂离，关闭连接报告离线，异常断连在心跳超时 45 秒内转离线。一个成员多个标签页合并计算，任一可见有效连接即在线。状态表示网站连接情况，不承诺用户一定能立刻回应。

## 各游戏操作反馈

棋盘类为落子和翻转提供短动画；记忆和配对提供翻牌、匹配反馈；卡牌提供出牌和发牌过渡；竞速类以服务端时间和结果为准，不把网络到达顺序当作设备反应速度。其余问答、推理、迷宫与合作游戏即时更新步骤、双方提交状态和聊天。为 20 个游戏逐一核对双方行为与隐藏信息规则。

动画长度以 120–220ms 为主，不锁住后续输入；低性能设备避免大面积重排，尊重 reduced-motion。按钮提供按下、处理中、失败和重试反馈，连接状态用简短文字表示。移动端触控区、公屏输入和弹出邀请不遮挡主要操作。

## 验收与回退

1. 两个独立身份连接，持续画线时对方在抬笔前逐段看到变化；落子、聊天、准备与邀请无需等下一轮轮询。
2. 在 RTT 不超过 100ms、无丢包的受控测试中，动作到对方呈现 P95 目标不超过 250ms；本地绘画按 60fps 调度。记录实际测量和设备条件，不以此保证所有手机或网络达到同样结果。
3. 覆盖乱序、重复、漏推送、断线重连、对象重启、换题、撤销、成员退出及双标签页；不得回滚状态、重复奖励或泄露秘密。
4. 覆盖好友接受／拒绝／离线回到网站／重复邀请，以及现有外部链接和钥匙登录。
5. 跑现有测试、类型检查、GitHub 与 Cloudflare 构建及 20 游戏集成检查；正式 API 另测真实 WebSocket 升级和两个客户端，确认生产前后端版本。实际双手机与微信环境未经测试时明确说明。
6. 新通道不可用时自动退回现有同步；发布可回退前端及 API，不删除旧 D1 数据、钥匙或奖励历史。
